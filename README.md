# Ponto Interno (Piloto)

Piloto de registro de ponto pelo celular, restrito ao local de trabalho (cerca virtual), com painel do gestor. Dados FICTICIOS. Controle interno - NAO substitui o ponto oficial.

- index.html = tela do funcionario (bater ponto)
- admin.html = painel do gestor (cerca virtual, painel do dia, funcionarios)
- setup.sql = estrutura do banco (Supabase)
